# 曲线、普通分割与带点分割的严格定义

设

\[
a,b\in\mathbb R,\qquad a<b,\qquad m\in\mathbb N,\qquad \exists r\in\mathbb N\ (1+r=m).
\]

设

\[
\gamma:[a,b]\to\mathbb R^m.
\]

定义由 \(\gamma\) 确定的带参数曲线为

\[
\mathcal C_\gamma
:=
\operatorname{Graph}(\gamma)
:=
\{(t,\gamma(t))\mid t\in[a,b]\}.
\]

即

\[
\mathcal C_\gamma\subseteq [a,b]\times\mathbb R^m.
\]

定义其轨迹集合为

\[
|\mathcal C_\gamma|
:=
\{p\in\mathbb R^m\mid \exists t\in[a,b]\ (p=\gamma(t))\}.
\]

也即

\[
|\mathcal C_\gamma|=\gamma([a,b]).
\]

## 曲线的普通分割

先定义候选集合

\[
\Omega_{a,b}
:=
\mathbb N\times \mathcal P(\mathbb N\times [a,b]).
\]

由分离公理，定义 \([a,b]\) 的全部普通分割组成的集合：

\[
\operatorname{Part}([a,b])
:=
\{P\in\Omega_{a,b}\mid \Phi_{\operatorname{part}}(P)\}.
\]

其中 \(\Phi_{\operatorname{part}}(P)\) 表示如下公式：

\[
\exists n\exists X
\Bigl[
P=(n,X)
\land
n\in\mathbb N
\land
\exists r\in\mathbb N\ (1+r=n)
\]

\[
\land\
\forall i\in\mathbb N
\Bigl(
\exists r\in\mathbb N\ (i+r=n)
\Rightarrow
\exists! t\in[a,b]\ ((i,t)\in X)
\Bigr)
\]

\[
\land\
\forall z\in X\ \exists i\in\mathbb N\ \exists r\in\mathbb N\ \exists t\in[a,b]\,
\bigl(i+r=n\land z=(i,t)\bigr)
\]

\[
\land\
(0,a)\in X
\land
(n,b)\in X
\]

\[
\land\
\forall j\in\mathbb N
\Bigl(
\exists r\in\mathbb N\ ((j+1)+r=n)
\Rightarrow
\exists u\exists v
\bigl(
(j,u)\in X
\land
(j+1,v)\in X
\land
u<v
\bigr)
\Bigr)
\Bigr].
\]

定义 \(\mathcal C_\gamma\) 的全部普通分割组成的集合为

\[
\operatorname{Part}(\mathcal C_\gamma)
:=
\operatorname{Part}([a,b]).
\]

其诱导的第 \(i\) 个曲线分点由如下关系定义：

\[
\operatorname{CPoint}(\mathcal C_\gamma,P,i,q)
\]

当且仅当

\[
\exists n\exists X\exists t
\Bigl[
P\in\operatorname{Part}([a,b])
\land
P=(n,X)
\land
i\in\mathbb N
\land
\exists r\in\mathbb N\ (i+r=n)
\land
(i,t)\in X
\land
(t,q)\in\mathcal C_\gamma
\Bigr].
\]

## 曲线的带点分割

先定义候选集合

\[
\dot\Omega_{a,b}
:=
\mathbb N\times\mathcal P(\mathbb N\times[a,b])\times\mathcal P(\mathbb N\times[a,b]).
\]

由分离公理，定义 \([a,b]\) 的全部带点分割组成的集合：

\[
\operatorname{TPart}([a,b])
:=
\{\dot P\in\dot\Omega_{a,b}\mid \Phi_{\operatorname{tpart}}(\dot P)\}.
\]

其中 \(\Phi_{\operatorname{tpart}}(\dot P)\) 表示如下公式：

\[
\exists n\exists X\exists\Xi
\Bigl[
\dot P=(n,X,\Xi)
\land
(n,X)\in\operatorname{Part}([a,b])
\]

\[
\land\
\forall i\in\mathbb N
\Bigl(
\exists h\in\mathbb N\ \exists r\in\mathbb N\ (1+h=i\land i+r=n)
\Rightarrow
\exists! \xi\in[a,b]\ ((i,\xi)\in\Xi)
\Bigr)
\]

\[
\land\
\forall z\in\Xi\ \exists i\in\mathbb N\ \exists h\in\mathbb N\ \exists r\in\mathbb N\ \exists \xi\in[a,b]\,
\bigl(1+h=i\land i+r=n\land z=(i,\xi)\bigr)
\]

\[
\land\
\forall j\in\mathbb N
\Bigl(
\exists r\in\mathbb N\ ((j+1)+r=n)
\Rightarrow
\exists u\exists v\exists \xi
\bigl(
(j,u)\in X
\land
(j+1,v)\in X
\land
(j+1,\xi)\in\Xi
\land
u\le \xi
\land
\xi\le v
\bigr)
\Bigr)
\Bigr].
\]

定义 \(\mathcal C_\gamma\) 的全部带点分割组成的集合为

\[
\operatorname{TPart}(\mathcal C_\gamma)
:=
\operatorname{TPart}([a,b]).
\]

其诱导的第 \(i\) 个曲线上标记点由如下关系定义：

\[
\operatorname{TPoint}(\mathcal C_\gamma,\dot P,i,q)
\]

当且仅当

\[
\exists n\exists X\exists\Xi\exists \xi
\Bigl[
\dot P\in\operatorname{TPart}([a,b])
\land
\dot P=(n,X,\Xi)
\land
i\in\mathbb N
\land
\exists h\in\mathbb N\ \exists r\in\mathbb N\ (1+h=i\land i+r=n)
\land
(i,\xi)\in\Xi
\land
(\xi,q)\in\mathcal C_\gamma
\Bigr].
\]
