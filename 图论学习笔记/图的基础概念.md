# 哲学思考
>这里对于之前的那种模糊的想法，我们更进一步。 
>>我现在最疑惑的就是，我们用符号“代指”一个东西这个“动作”。也就是前面说的“指称”，它到底要怎么做才可以“看着合理”点。
就比如，用符号A代表一个集合。 符号A本身只是一个符号，集合直观上绝对不是一个符号。那么我们就是在用符号“指称”这个集合。   包括，我们说“这个人”  “这个人”这几个汉字，本身只是符号， 人显然不只是这几个汉字符号。我们用“这个人”这几个汉字“指称”了人这个实体。
好，现在，我们讨论的就是“指称”这个动作本身。他是个啥？？
>>>然后就又想到了我之前书上的一个东西，我们扩展一下呢？
依旧论域，依旧模型，依旧赋值函数
论域在这里不能是集合，虽然书上那个说是集合，但是我们现在不在书本的那个讨论的层级，在比它更原始的层级。模型，这个还是沿用书上，就是函数（*这个函数本身也是更加原始的概念，不是书上那种依赖集合论定义的函数*）  赋值函数，同上。
>>>>有了上述基础。我们肯定的说：函数是一个客观的存在，它类似一个电话册，电话册记录电话号码和人的对应关系，函数记录源对象和目标对象的对应关系。（**这其实就涉及到哲学立场了，这不一定是对的，但是是理解的一个角度**）
>>>>>进一步，我们具体的有：
1.“模型函数”
2.“赋值函数”
3.“论域内对应函数”
上述函数都是“承认与约定”
>>>>>>如果还想再进一步，你可能发现<u>函数本身的归属</u>我们并没有讨论。
所以，更进一步！先验<u>承认</u>一个大世界的存在。这个大世界里有一切。我们的论域，符号表是大世界的片段是大世界的构成部分，一切的概念是大世界的构成部分，一切的函数实体是大世界的构成。（**当然，这依旧是一种哲学立场**）
